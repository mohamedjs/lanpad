Built for fluid precision

Designed to feel like the keyboard and mouse are directly wired to the machine.

⚡

5-Byte Binary Frames

Packs mouse moves into tight 5-byte delta buffers instead of heavy 30-byte JSON strings. Zero serialization overhead, zero lag.

🖐️

Native Momentum Gestures

Two-finger scroll glides with sub-pixel momentum. Pinch-to-zoom and two-finger left/right swipes map seamlessly to workspace switching.

🔒

Keyboard Lock & TLS

Self-signed HTTPS unlocks Chrome's Keyboard Lock API so Esc, Tab, and Cmd shortcuts pass through directly without being eaten by macOS.

📶

Wi-Fi Power-Save Heartbeat

Sends a 1-byte keepalive every 16ms during active capture so the laptop Wi-Fi radio never enters sleep state mid-drag.

📱

Expo 58 Mobile Remote

Turn your phone or tablet into an emergency wireless touchpad and keyboard with tap-to-click, scroll bars, and haptic feedback.

🛡️

100% Local & Private

Traffic never leaves your local Wi-Fi network. Protected with a constant-time secret token generated on your host machine.

Modular Monolith Architecture

Clean, decoupled domain architecture inspired by Lura.


src/lanpad/
├── app.py            ── CLI presentation layer (serve, selftest, token)
├── bootstrap.py      ── Composition root: the ONLY file that wires modules
├── selftest.py       ── Comprehensive end-to-end self-diagnostics
├── shared/           ── Cross-platform kernel (paths, network, protocol, errors)
└── modules/
    ├── auth/         ── TokenService: constant-time verification & rotation
    ├── input/        ── Cross-platform mouse & keyboard engine:
    │                    ├── linux.py   (X11 Xlib + XTEST)
    │                    ├── windows.py (ctypes user32 SendInput)
    │                    └── macos.py   (CoreGraphics / Quartz)
    └── server/       ── High-performance HTTP & WebSocket server

Frequently Asked Questions

Do I need to install anything on the Mac or client laptop?

No! Open the URL printed by LANpad in Chrome or any Chromium browser. Pointer Lock and full keyboard capture work right inside the browser.

How does the phone / tablet app work?

The mobile app is built with modern Expo 58 (React Native). It connects to the same LANpad WebSocket port over Wi-Fi and provides a touch trackpad with haptic feedback.

Why does Chrome ask about a self-signed certificate when --tls is on?

LANpad generates a local certificate on your machine for HTTPS. Chrome requires a secure context (HTTPS) to unlock the Keyboard Lock API so full-screen Esc, Tab, and Cmd keys reach your remote desktop.
